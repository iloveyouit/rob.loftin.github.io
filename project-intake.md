# Project Intake Form (Pre-Publish)

Use this intake before creating or updating a project.

## Required Fields
- [ ] Project title
- [ ] Client type / industry (anonymized if needed)
- [ ] Project timeline
- [ ] Core problem statement
- [ ] Scope boundaries (in/out)
- [ ] Tool stack used
- [ ] Your role and team involvement

## Evidence & Metrics
- [ ] Baseline (before state)
- [ ] Final state (after)
- [ ] At least 1 quantified KPI
- [ ] Preferred: 2–3 KPIs
- [ ] Evidence source (report, dashboard, logs, ticket metrics)

## Risk & Compliance Check
- [ ] No client-identifying sensitive information
- [ ] No credentials/secrets/config leaks
- [ ] Compliance-safe wording for regulated environments

## Portfolio Mapping
- [ ] Add/Update object in `data/projects.json`
- [ ] Add `caseStudyUrl`
- [ ] Add or update `case-study/<slug>.html`
- [ ] Confirm project appears on `projects.html`

## Quality Gate (Publish only if true)
- [ ] Outcome is specific, not generic
- [ ] Business value is clear
- [ ] Copy is typo-free
- [ ] CTA present
