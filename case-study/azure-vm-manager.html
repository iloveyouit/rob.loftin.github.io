Azure VM Manager

A portal-style operations platform that treats change safety, evidence, and operator intent as first-class product requirements.

The problem

Routine Azure lifecycle actions become risky when scope, cost, dependencies, approvals, recovery, and audit evidence live in separate tools or only in an operator’s head.

The system

The application brings inventory, power actions, snapshots, patching, maintenance windows, policy, cost signals, approvals, simulations, runbooks, dependencies, and operation history into one React and Flask experience backed by the Azure SDK and Entra ID.

Safety design

  • Simulation and dry-run previews before risky actions.
  • Backend-enforced approvals for guarded operations.
  • Recovery points, dependency context, cooldowns, and post-action evidence.
  • Audit history, policy checks, release gates, and exportable reports.

Verified state

Version 1 was sealed after 71 roadmap items. Later work added guarded bulk actions, an executable patch-and-snapshot runbook path, and Azure Policy integration. A September 2026 verification run covered 71 backend tests and 59 frontend tests. Production adoption and savings metrics are not yet claimed.
