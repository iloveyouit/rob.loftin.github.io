# Project Case Study Template

Use this template for every new project under `case-study/<slug>.html`.

## 1) Project Snapshot
- **Title:**
- **Client Type / Industry:**
- **Timeline:**
- **Role:**
- **Primary Outcome:**

## 2) Business Context
Describe the business problem in plain language.
- What was happening?
- Why did it matter?
- What was at risk if unchanged?

## 3) Constraints
List constraints that shaped decisions:
- Time
- Budget
- Security / compliance
- Team capacity
- Legacy systems / technical debt

## 4) Architecture & Approach
Summarize how the solution was designed.
- Core components
- Tooling choices and why
- Tradeoffs considered

## 5) Implementation
Break down execution in sequence.
1. Discovery / baseline
2. Design / validation
3. Build / automation
4. Rollout / change management
5. Monitoring / optimization

## 6) Results (Quantified)
Use before/after metrics where possible.
- KPI 1: before → after
- KPI 2: before → after
- KPI 3: before → after

## 7) Business Impact
Connect technical outcomes to business value.
- Cost reduction
- Risk reduction
- Revenue enablement
- Delivery speed improvements

## 8) Lessons Learned / Next Phase
- What worked best?
- What would you change?
- What is phase 2?

## 9) Stack
List concrete technologies used.

## 10) CTA
Add one clear CTA line (Discovery call, scope request, etc.).
